Mulai Belajar

1. Ringkasan Rumus Dasar & Sudut Rangkap

Sebelum masuk ke materi kelas 12, pastikan kamu mengingat kembali identitas dan rumus sudut rangkap berikut:

Identitas Trigonometri Dasar

  • • $\sin^2 x + \cos^2 x = 1$
  • • $1 + \tan^2 x = \sec^2 x$
  • • $1 + \cot^2 x = \csc^2 x$

Rumus Sudut Rangkap

  • • $\sin 2x = 2 \sin x \cos x$
  • • $\cos 2x = \cos^2 x - \sin^2 x = 1 - 2\sin^2 x = 2\cos^2 x - 1$
  • • $\tan 2x = \frac{2 \tan x}{1 - \tan^2 x}$

2. Limit Fungsi Trigonometri

Limit fungsi trigonometri adalah nilai yang mendekati suatu sudut pada fungsi trigonometri saat peubahnya mendekati nilai tertentu.

Teorema Dasar Limit Trigonometri ($x \to 0$):

$\lim_{x \to 0} \frac{\sin x}{x} = 1$
$\lim_{x \to 0} \frac{x}{\sin x} = 1$
$\lim_{x \to 0} \frac{\tan x}{x} = 1$
$\lim_{x \to 0} \frac{x}{\tan x} = 1$

Contoh Soal & Pembahasan:

Tentukan nilai dari: $\lim_{x \to 0} \frac{\sin 3x}{2x}$

Penyelesaian: Menggunakan sifat dasar limit $\lim_{x \to 0} \frac{\sin ax}{bx} = \frac{a}{b}$, maka:
$\lim_{x \to 0} \frac{\sin 3x}{2x} = \frac{3}{2}$

3. Turunan Fungsi Trigonometri

Turunan fungsi trigonometri melibatkan laju perubahan fungsi trigonometri terhadap variabel sudutnya.

Rumus Dasar Turunan:

  • • Jika $f(x) = \sin x$, maka $f'(x) = \cos x$
  • • Jika $f(x) = \cos x$, maka $f'(x) = -\sin x$
  • • Jika $f(x) = \tan x$, maka $f'(x) = \sec^2 x$

Aturan Rantai (Chain Rule):

  • • Jika $f(x) = \sin(ax+b)$, maka $f'(x) = a \cdot \cos(ax+b)$
  • • Jika $f(x) = \cos(ax+b)$, maka $f'(x) = -a \cdot \sin(ax+b)$
